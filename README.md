# IPv4 and IPv6 Hex to Decimal Converter

A Java console application that converts hexadecimal values to decimal for both IPv4 and IPv6 address formats.

---

## Features
- Converts IPv4 hexadecimal values to decimal (4 octets)
- Converts IPv6 hexadecimal values to decimal (8 groups)
- Option to repeat conversion without restarting the program

---

## Requirements
- Java JDK 8 or higher

## How to Use

1. Select option `1` for IPv4 or `2` for IPv6
2. For **IPv4**: Enter 2 hexadecimal digits per octet (8 inputs total)
3. For **IPv6**: Enter 4 hexadecimal digits per group (32 inputs total)
4. The converted IP address will be displayed
5. Enter `0` to exit or any other number to convert again
